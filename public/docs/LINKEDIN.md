## English

Does a faster machine always mean a better factory?

I built IndustrialOS Factory Lab, an interactive 3D experiment in production bottlenecks.

For a three-station line processing ten pieces, including travel time:

- Baseline batch: 455 seconds.
- Halve station A's cycle time: 445 seconds, a 2.2% reduction.
- Halve station B's cycle time: 300 seconds, a 34.1% reduction. The constraint moves to C.

The project connects a local improvement decision to system-level outcomes. You can change inputs, compare both runs, inspect the event log and share a reproducible experiment.

The deterministic engine is separate from the 3D renderer, with Arabic and English interfaces. These are synthetic model outcomes, not measured savings in a real factory.
